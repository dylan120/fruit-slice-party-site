# Fruit Slice Party Site

Fruit Slice Party 的静态产品、隐私和支持网站，作为 App Store Connect 的公开营销、支持与隐私入口。

## 本地预览

```bash
python3 -m http.server 8000 --directory ..
```

访问 `http://localhost:8000/fruit-slice-party-site/`。

## 验证

```bash
bash scripts/validate.sh
```

正式发布目标为 `https://dylan120.github.io/fruit-slice-party-site/`。
